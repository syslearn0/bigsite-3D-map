# コミケ 3D マップ（見本）

東京ビッグサイトの会場を 3D で見て、行きたいサークルの計画を立てる Web アプリの見本。
コミックマーケット準備会・株式会社東京ビッグサイトとは関係のない、個人の試作です。

**いまの島の配置・作品は見本です。C109（2026年12月29〜31日）の本当の配置ではありません。**

## できること
- 見方を3つ切り替える：上から（地図のように）・3D（回して見る）・歩く（一人称）
- 1F と 4F を切り替える（西3・4、南3・4 は 4F）
- 配置番号（例：東A-01a）で机を探す。机を押すと配置番号が出る
- 「行きたい」に入れる（この端末の中だけに保存）
- 作品ごとの色分け（見本）

## データ
| 中身 | 出典 |
|---|---|
| ホール・通路・まわりの建物・トイレの形と位置 | © OpenStreetMap contributors（ODbL 1.0）。`npm run fetch:osm` → `npm run build:venue` |
| 机の配置（見本） | `npm run build:layout` が、ホールの形から仮に並べる。島の大きさはコミケの長机（1800×450mm）、1スペース＝机半分（a・b） |

- ホール同士の位置関係は OSM の緯度経度のまま。
- 南展示棟は OSM に外形1つしかないので、ホールの部分を切り出した概略。1F（南1・2）と 4F（南3・4）は同じ形にしている。
- 東4〜6ホールは改修工事中のため、C109 では使わない（机を置かない）。
- ビッグサイトの主催者向け図面（白図）は、規約で再配布・改変ができないので、このリポジトリには入れない（`data/private/` は git に入らない）。

## 机の配置の形（あとで島を並べるエディタもこの形を書き換える）
`src/data/layout-sample.json` の `lines` が、島の列（ブロック）1つずつ：

```json
{ "hall": "E1", "block": "A", "start": [x, z], "angle": 0.78, "segments": [16, 16], "genre": "作品A" }
```

- `start`：島の中心線の始点（会場の中のメートル。x が東、z が南）
- `segments`：横切る通路で区切られた区間ごとの机の数
- 番号は A側を始点から進み、B側を戻る。机1つが番号1つで、左右の半分が a・b
- 計算は `src/lib/layout.ts` の `expandBooths`
